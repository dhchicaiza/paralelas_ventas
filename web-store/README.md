# TechStore - Frontend

Tienda virtual moderna y responsive construida con React, TypeScript y Bootstrap.

## 🚀 Tecnologías

- **React 19** - Biblioteca UI
- **TypeScript 5** - Tipado estático  
- **Vite** - Build tool y dev server
- **React Router 7** - Routing
- **Bootstrap 5** - Framework CSS
- **React Bootstrap** - Componentes de Bootstrap para React
- **Zustand** - Gestión de estado global
- **React Hot Toast** - Notificaciones

## 📋 Características

✅ Catálogo de productos con filtros  
✅ Carrito de compras persistente  
✅ Proceso de checkout completo  
✅ Diseño responsive  
✅ Notificaciones toast  
✅ 12 productos de ejemplo  

## 🛠️ Setup

```bash
npm install
npm run dev
```

Abrir: `http://localhost:5173`

## 📁 Estructura

```
src/
├── components/    # Componentes React
├── pages/        # Páginas (Home, Products, Cart, Checkout)
├── store/        # Zustand store (carrito)
├── types/        # TypeScript types
├── data/         # Productos mock
└── App.tsx       # Componente principal
```

## 🎯 Páginas

- `/` - Home
- `/products` - Catálogo
- `/cart` - Carrito
- `/checkout` - Finalizar compra

Listo para integrar con la API de ventas!
